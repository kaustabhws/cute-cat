# Icon provenance

`app.ico` is rendered from the original C# cat geometry in `CatPainter.DrawIcon`, through `QualityChecks.ExportArt`. It contains 16, 24, 32, 48, 64, 128 and 256-pixel PNG images inside a Windows ICO container. The production character animation does not load this icon or any diagnostic PNGs.

Created 12 September 2026 in this repository. No external cat artwork, competitor code or generated images were used. The user's supplied pictures guided simplicity only. See `docs/04-art-direction.md` and `docs/05-art-production.md`.

Re-rendered for 0.5.0 from the softer character revision 2, using the same front-facing head geometry as its turning animation.
