# Cute Cat 1.1.1

Smoother app controls and window resizing, a larger cat wardrobe, and more ways to keep your focus. This release includes the features developed locally in 1.1.0 and the 1.1.1 responsiveness improvements.

## What's new

- Smooth toggle transitions and layout reflow when maximizing, restoring or resizing the app. Background settings saves, cached wardrobe previews and fewer redundant refreshes reduce UI work.
- Desktop and Start menu shortcuts now open the existing app window when Cute Cat is already running, including restoring minimized windows.
- Solid, tabby, tuxedo and calico coat patterns, separately coloured accessories, and saved outfits that can be linked to focus profiles.
- A grace countdown beside the cat with **Allow 5 minutes**. A rule with zero grace retains its immediate paw response.
- Expressive petting with an optional soft purr, plus optional stretch/water reminders. Taking a break preserves focus progress for **Back to focus**.
- A Troubleshooting page with menu/notification tests and a privacy-safe support report. Settings export/import includes a review of app rules before enabling protection.

## Startup and upgrade behavior

The first normal launch of 1.1.1 enables **Start with Windows**, including on an existing installation. The cat starts quietly with the main window closed. You can switch this off in Settings; subsequent choices are remembered.

Settings, outfits and focus history are preserved. State schema 5 keeps a separate copy of schema-4 settings when upgrading from 1.0.0. App guard and notification dismissal remain separate user choices. Imported rules start unchecked and monitoring stays off until enabled. Browser URL detection remains deferred.

## Download and validation

Use **CuteCat-1.1.1-Setup.exe** on Windows 11 x64. The installer registers Cute Cat in Windows Installed apps and supports uninstall from there. This is the same installer validated and installed locally before publication.
