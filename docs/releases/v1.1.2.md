# Cute Cat 1.1.2

Fixes App guard failing to react to selected applications.

## Fixes

- A slow Windows notification query no longer blocks App guard from checking other apps. Only one notification scan remains in flight, and cancelled results are discarded.
- Custom window frames with empty legacy close-button bounds can use verified native close hit-testing. This addresses the frame behavior observed in Android Studio and Codex without app-specific coordinates.
- Eligible dialog-based main windows used by desktop utilities can now be selected. Owned dialogs and ordinary save/message prompts remain excluded.
- Status messages distinguish missing app rules, unavailable foreground state, and slow notification discovery.

Closing still requires the selected executable, foreground window, current rule and painted paw contact. Requests are normal window closes; save/exit prompts and refusals stay under your control. Unsupported frames and close controls outside the cat's selected monitor remain subject to the documented limits.
