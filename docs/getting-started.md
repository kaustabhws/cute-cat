# Getting started

## Open the app

For **0.8.0**, download `CuteCat-0.8.0-Setup.exe` from the repository's Releases. Use **App guard → Add an app**, choose close/reminder and scope, then enable the guard. No apps are selected automatically. **Your cat** contains activity, idle-nap, accessory and colour choices. The pet and notification-area icon share the themed menu.

The bandana, bow tie and collar sit at the neck behind the chin; the flower sits at the ear. Sleep/wake, the nose bubble and floating z symbols are generated by code. App closes are ordinary window-close requests; save prompts stay yours to answer. Browser URL/tab rules remain deferred.

Run `dist/installer/CuteCat-0.8.0-Setup.exe` for the native installation wizard. It adds Cute Cat to the Start menu and Windows Installed apps, with an optional desktop shortcut. New installations use `C:\Program Files\Cute Cat`; an existing reviewed manual installation can be adopted in place. The wizard explains notification access and preserves existing user preferences.

To remove the installed app, open **Settings → Apps → Installed apps → Cute Cat → Uninstall**. The uninstaller closes Cute Cat, removes the program, shortcuts, registration and owned certificate trust, and preserves settings/focus history for a later reinstall. Startup is not enabled by Setup.

Use the Start menu or desktop **Cute Cat** shortcut. `scripts/run.ps1` also selects the registered version while its signature is valid/trusted. The installer shows the preview certificate's expiry. See [profiles and reliability](19-profiles-and-reliability.md) for signing, updates and recovery.

The standard development fallback is `CuteCat.exe` inside `dist/CuteCat-0.8.0`, or `scripts/run.ps1 -Standard`. Keep the portable folder together. Both Windows x64 builds contain the .NET runtime. The standard build is unsigned and needs no administrator rights or UIAccess; verified installation through the updater requires a signed app.

The control window includes:

- **Focus:** 25/50-minute or custom 5–180-minute sessions, pause/resume/end, optional five-minute break, today/week completed minutes.
- **Profiles:** Work, Study and Break, independent app rules/activity, weekly local-time schedules. Manual selection pauses schedules until re-enabled.
- **App guard:** per-app close/reminder, scope, 0–60 second grace, daily allowances, and Allow 5/15/30 minutes. Daily totals remain local for 14 days.
- **Your cat:** nickname, walk/run/meow/groom/play/sleep/wake, Turn around replay, quiet activity, show/hide and park.
- **Quiet desktop:** explanatory opt-in for the Windows banner helper; practice card; real Windows test.
- **Settings:** theme, size, monitor resting spots, settling during work, optional geometry-only focused-control avoidance, reduced motion, sound, startup and local data clearing.
- **Updates & recovery** inside Settings: optional GitHub checks, verified downloads, user-initiated installation and saved compatible installers. 0.8 establishes the recovery baseline.

Click the desktop cat to greet it; drag to move; right-click for its menu. Closing the control window leaves the cat in the tray. Double-click the tray icon to reopen it; **Quit** ends the app. Hidden cats do not stop the timer. Focus sessions intentionally quiet autonomous wandering.

## Try the paw

Choose **Quiet desktop → Try a practice card**. This explicitly creates an app-owned card and runs the cat's approach/contact/dismissal. It works without enabling automatic Windows dismissal. Disable reduced motion to see the approach.

To try a real Windows banner, enable **Dismiss Windows banners with a paw**, then choose **Send Windows test**. The cat runs from its current position and reaches the cross before the control is invoked. Do Not Disturb, full-screen/busy state or a locked desktop can suppress this app's test. Version 0.6.1 has detected and dismissed a real Windows toast using the user's Snipping Tool layout. Unknown layouts and targets outside the selected monitor are left alone.

Windows renders its notifications above ordinary desktop windows, so the standard cat can be hidden where it overlaps a banner. The user explicitly approved the [UIAccess test installation](16-uiaccess-review.md), and its actual runtime/window order now places the cat above the notification layer. Its broader permissions, certificate expiry and rollback are documented there. Final visual feedback on the installed interaction was requested separately.

The app attempts standard-user launch, but the administrative UIAccess test environment has also produced elevated runtime tokens; broad standard-user coverage remains a desktop test gate. No Windows account, UAC or notification policy setting is changed. The notification helper remains optional for new users.

## Local data

State lives in `%LOCALAPPDATA%/CuteCat/state.json`. Writes are atomic with a previous-version backup. The earlier flat `Version: 1` format migrates with a separate `.legacy-v1.json` copy; active sessions recover paused. Malformed files are preserved; unknown/future schemas are read-only. `--data-dir PATH` selects an isolated development folder.

No account, hosted backend, generated animation assets or API key is needed. Optional update checks/downloads connect to GitHub; normal companion behavior stays local. Startup and sound are opt-in. Website protection is future work.

## Build and verify

```powershell
./scripts/build.ps1 -Publish
dotnet src/CuteCat.App/bin/Release/net10.0-windows10.0.19041.0/CuteCat.dll --qa artifacts/qa-local
dotnet src/CuteCat.App/bin/Release/net10.0-windows10.0.19041.0/CuteCat.dll --benchmark artifacts/performance-local
```

`--qa` uses its own state, exercises native windows and production handlers, and produces inspectable evidence. `--benchmark` runs five minutes each of idle and movement with the control window hidden. `--shell-check PATH` temporarily enables the helper in an isolated profile and sends a real Windows test; run it on a normal interactive desktop. See the build status for exactly what was verified here.
